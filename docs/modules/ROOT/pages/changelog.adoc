== 2026-09-10 — Publish robots.txt with sitemap

* Antora `site.robots` now emits `/robots.txt` with an absolute `Sitemap:` line for the production host.

== 2026-09-07 — Brand mark redraw

* Synced the docs header and component image to the canonical two-pane desktop window and hex-drive socket glyph.

== 2026-09-07 — Component catalog

* Renamed the portal component to Home and moved the complete eight-component catalog onto its landing page.
* Added every catalog project as a first-class Antora component in the curated navigation tree.
* Adopted the current Facto extension and companion UI defaults.

== 2026-09-02 — OPR boundary note

* xref:division-of-labor.adoc[Division of labor]: Open Provider Registry / machine-local model discovery belongs in Dev-Centr (`uniprovider`), not Desktop Tooling.

== 2026-09-02 — Tool-run stakeholder boundary

* xref:division-of-labor.adoc[Division of labor]: OpenShellOrg owns Tool Run bus; HCI owns programmer-POV patterns; Desktop Tooling may supply OS flash/tray helpers only; Dev-Centr embeds the library in agent harnesses.

== 2026-08-18 — Organization bootstrap

* Public Antora hub with Valentus v2, Lunr, search-chat, and KaTeX.
* Pages for division of labor, principles, and the first catalog.
* Details: the org `.github` changelog records the same date.
