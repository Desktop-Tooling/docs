= Division of labor
:description: What belongs in Desktop Tooling versus HCI Nerdz, OpenShellOrg, and Dev-Centr.

== Rule of thumb

[cols="1,1,1,1"]
|===
| Desktop Tooling | HCI Nerdz | OpenShellOrg | Dev-Centr

| How should the *OS desktop* behave?
| How should humans *see and manipulate* systems?
| How should CLIs and shells *speak and compose*?
| How should *developer machines* be configured?

| Explorer, shell extensions, theming, launchers, windowing
| Surfaces, themes-as-contracts, dialogs, attention, product representation
| Flags, pipes, entrypoints, help budgets, SOS
| Toolchains, package hubs, agent rules, environment orchestration
|===

Cross-link sibling orgs. Do not absorb them.

== Boundary examples

[cols="1,1"]
|===
| Topic | Home

| SVG thumbnail handler in Explorer
| Desktop Tooling (`svgesus`)

| Custom dialog *pattern* for Electron (honest surfaces)
| HCI Nerdz (`electron-custom-dialog`)

| Progressive CLI help (Prohelp)
| OpenShellOrg

| “Open with Cursor” Explorer verb for developers
| Dev-Centr

| Activity map / window launcher
| Desktop Tooling (`activity-map-shell`)

| Piles canvas/sentiment inbox *pattern* and demos
| HCI Nerdz (`piles`)

| Piles installed mail client (IMAP, SQLite, Avalonia)
| Desktop Tooling (`piles`)

| Context rails / pipeline composer experiments
| HCI Nerdz

| Spatial web windows *interaction pattern* and demo
| HCI Nerdz

| Chromium fork for browser windowing (`spatial-browser`)
| Desktop Tooling

| Intent routing for UI-heavy / WASM web apps
| Dev-Centr

| Tool-run bus, wrappers, shell session ids, compile diagnostics protocol
| OpenShellOrg (link:https://opensh.org/docs/shell-architecture/tool-run-diagnostics.html[tool-run diagnostics])

| Programmer-POV diagnostic wording / channel-switcher patterns
| HCI Nerdz

| OS desktop flash, tray, or focus helpers when a tool-run index lives outside an IDE
| Desktop Tooling (helpers only — do not redefine the bus)

| Agentic harness embedding of tool-run widgets (`embed` / timeline)
| Dev-Centr (consumes OpenShellOrg library contract)
|===
