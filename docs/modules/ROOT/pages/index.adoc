Desktop Tooling builds focused utilities that improve everyday Windows desktop work: managing windows and processes, extending File Explorer, following a theme schedule, bridging hardware, and providing guided assistance.

== Projects

* xref:home::index.adoc[Home] — This portal and catalog for the complete Desktop Tooling documentation set.
* xref:activity-map-shell::index.adoc[Activity Map Shell] — A Windows activity map for arranging process and window blocks, launching apps, and returning to attached windows.
* xref:thumbelina::index.adoc[Thumbelina] — A multiboot USB manager for live ISOs, thin Btrfs installations, or both on one drive.
* xref:svgesus::index.adoc[SVGesus] — A Windows shell extension that renders SVG files as File Explorer thumbnails.
* xref:explorer-refresh-thumbcache::index.adoc[Explorer Refresh Thumbcache] — A File Explorer context-menu command that clears thumbnail caches and restarts Explorer.
* xref:windows-theme-autochanger::index.adoc[Windows Theme Autochanger] — A Windows background service and tray app that switches light and dark themes on a schedule.
* xref:nikon-camera-bridge::index.adoc[Nikon Camera Bridge] — A Windows-first bridge toward Nikon USB video, a virtual camera, and HTTP camera controls.
* xref:desktop-assistant-ai::index.adoc[Desktop Assistant AI] — An experimental Windows assistant for coding and desktop guidance using screenshots, speech, and AI models.

== Scope

Desktop Tooling owns OS-level desktop utilities. Interaction-design research belongs to link:https://hci-nerdz.github.io/[HCI Nerdz], shells and command-line composition belong to link:https://openshellorg.github.io/[OpenShellOrg], and developer-machine tooling belongs to link:https://devcentr.org/[Dev-Centr].

For the detailed boundary, read xref:division-of-labor.adoc[Division of labor] and xref:principles.adoc[Principles].
