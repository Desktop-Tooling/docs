= spatial-browser
:description: Chromium fork for spatial web windows — workspace grouping and parent-relative palette windows.

link:https://github.com/Desktop-Tooling/spatial-browser[spatial-browser] is a Desktop Tooling Chromium fork that implements browser-level support for link:https://hci-nerdz.github.io/docs/hci-nerdz/spatial-web-windows.html[spatial web windows].

== Why a fork

Stock browsers lack:

* Parent-relative always-on-top for same-origin palette windows
* Logical workspace grouping (viewport + palettes) on the OS taskbar
* Reduced background throttling among workspace peer windows

Web apps can partially compensate with Document PiP and chromeless popups; professional multi-window workflows need browser cooperation.
